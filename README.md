🚀 Modern Portfolio - Diego Santos
Este é o meu portfólio pessoal, projetado para exibir minhas habilidades como Java Specialist e Backend Engineer. O projeto foca em uma experiência de usuário fluida, com integração em tempo real com a API do GitHub e visual moderno inspirado em dashboards de alta performance.

🛠️ Tecnologias e Bibliotecas
O projeto foi construído utilizando uma arquitetura leve e performática:

Frontend: HTML5, CSS3 (Custom Variables), JavaScript (ES6+).

Animações: AOS (Animate On Scroll) para revelação de elementos.

Efeitos Visuais: tsParticles para o fundo interativo e Typed.js para o efeito de digitação.

Gráficos: Chart.js para visualização de dados do GitHub.

Integração: GitHub REST API para consumo de dados em tempo real.

Estilização: Tailwind CSS para utilitários de layout.

📊 Funcionalidades em Destaque
Dashboard GitHub Dinâmico
Implementei um sistema de consumo assíncrono que busca meus dados diretamente da API do GitHub:

Status Geral: Contagem em tempo real de Repositórios, Stars e volume de Commits.

Análise de Linguagens: Gráfico de rosca (Doughnut) que calcula a porcentagem de tecnologias utilizadas em todos os projetos.

Fluxo de Atividade: Gráfico de linha demonstrando a constância de desenvolvimento.

Dark/Light Mode Interativo
O tema do portfólio não altera apenas cores, mas também recalibra a cor das partículas de fundo para garantir contraste e acessibilidade.
